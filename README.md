# Sales Analytics Dashboard

## 📊 Project Overview

This project is a Sales Analytics Dashboard created using PostgreSQL and Power BI.

The project analyzes sales data to identify important business trends, customer performance, product performance, and overall sales insights.

## 🛠️ Tools & Technologies

- PostgreSQL
- SQL
- Power BI
- DAX

## 📌 Project Workflow

1. Imported and prepared the sales data in PostgreSQL
2. Performed data analysis using SQL queries
3. Connected the data with Power BI
4. Created KPIs and interactive visualizations
5. Analyzed sales and business performance
6. Created an interactive Power BI dashboard

## 📈 Dashboard Features

- Sales Performance Analysis
- Revenue Analysis
- Customer Analysis
- Product Analysis
- KPI Cards
- Interactive Filters and Slicers
- Charts and Visualizations

## 💡 Key Insights

The dashboard helps identify sales trends, top-performing products and customers, and overall business performance.
